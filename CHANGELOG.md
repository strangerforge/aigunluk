# Changelog

All notable platform milestones for **AI Günlük** are documented in this file.

## [1.0.0] - 2026-11-19

### Highlights
- **Autonomous 24/7 AI News Pipeline:** Automated global and Turkish AI ecosystem scanning via scheduled workflows.
- **Full-Article Turkish Briefings:** Full-text extraction and 5–7 sentence editorial synthesis in Turkish (TR).
- **Social Radar:** Curated high-signal YouTube and X discussions integrated into the main feed.
- **Swiss Editorial UI & PWA:** Warm Ivory light theme, Carbon Dark mode, smart category filters, and offline-capable Progressive Web App installation.
